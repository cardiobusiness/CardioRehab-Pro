# Relatorio final

O PDF final deve conter:

- Dados do paciente.
- Estratificacao de risco.
- Sensor utilizado.
- FC minima, media e maxima.
- PA inicial, durante e final.
- Duplo produto inicial, pico e final.
- Borg inicial e final.
- Sintomas.
- Intercorrencias.
- Evolucao da sessao.
- Observacoes do fisioterapeuta.
- Conduta sugerida.
- Trechos de ECG quando registrados no Polar H10.
